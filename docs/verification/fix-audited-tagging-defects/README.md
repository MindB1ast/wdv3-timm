## Что изменилось

- TXT сохраняются атомарно: ошибка чтения, записи или замены сохраняет прежние
  байты. Добавление тегов устраняет повторы и сохраняет порядок прежней подписи.
- Фильтры работают с каноническими именами и словарями; caption и taglist
  строятся из принятых general/character. Учитывается объединение исключений
  непустых детекторов, сохраняются character и максимальные модельные scores.
- Ручные теги имеют происхождение manual_rule; существующий модельный score
  сохраняется. Удаление имеет приоритет над ручным добавлением.
- Оценка учитывает все размеченные изображения и пропуски; доступны покрытие,
  отсутствующие ID и TP/FP/FN. Относительные ID различают одноимённые файлы.
  Историческая формула F1 сохранена и явно подписана.
- PNG/JPG с рамками записываются Pillow; интерактивный Plotly сохранён.
  Исходные PIL-файлы закрываются также при исключении и пустой детекции.

## Повторный запуск и ограничения

Из корня перенесённой копии:

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.\temp\apply-runtime\Scripts\python.exe audit/run_checks.py
.\temp\apply-runtime\Scripts\python.exe audit/run_integration.py
.\temp\apply-runtime\Scripts\python.exe audit/run_mutations.py
```

Интеграционный запуск требует уже скачанных локальных весов и создаёт файлы
только в temp. Версии Python и пакетов сохранены в `environment.json`.
Локальное apply-runtime использует пакеты перенесённого runtime311 через .pth;
старый launcher runtime311 после переноса не работает. Для переноса на другую
машину нужно отдельное окружение Python 3.11 с зависимостями проекта.

GPU, другие архитектуры WD, другие детекторы и установка ComfyUI здесь
не проверялись. Задачи add-comfyui-regional-tagging-nodes не реализованы и
не отмечались выполненными. Текущее исправление можно проверять и архивировать
отдельно, затем возвращаться к интеграции ComfyUI.
