## Совместимость и точечные исключения

Глобальное отключение проверок, повышение лимитов сложности и настройка формулы
оценки не применялись. Сохранены явно отмеченные исключения:

- C0103 для старых путей `Scripts`/`savingProc`, имени `BatchTagging` и поля
  `ImageFolder`: переименование нарушило бы действующие импорты/вызовы.
- R0913/R0917 для существующих позиционных сигнатур `tag_image`,
  `process_image_with_multiple_detectors`, `apply_tag_rules`,
  `compare_tagging_methods`: вызывающий код не требуется переписывать.
- R0902 для плоских публичных dataclass-конфигураций `DetectorConfig` и
  `ScriptOptions`: это поля данных, а не скрытая логика объекта.

Остальные замечания исправлены в коде. Исключений для больших функций,
числа локальных переменных, сложности ветвления, импортов или обработки ошибок нет.
Сигнатуры публичных функций и конструкторов/методов конфигураций и TagManager
сопоставлены со снимком до очистки: `api-compatibility.json`.
