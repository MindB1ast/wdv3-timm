# Ручная проверка ComfyUI

По указанию пользователя computer use не используется. Этот список выполняется
пользователем; автоматические тесты не заменяют визуальную приёмку задачи 3.1.
Используйте отдельный пустой workflow, не запускайте очередь: модели для этой
проверки не нужны.

1. Обновить страницу ComfyUI с очисткой кэша (Ctrl+F5). Добавить Tag Image / Regions.
2. Правой кнопкой по входу `wd_model` → «WDV3: подключить источник» → Load Tagger Model.
   Должны появиться нода и связь с `wd_model`. Ctrl+Z и Ctrl+Y должны отменять и
   восстанавливать действие без лишних связей.
3. Аналогично проверить входы `options`, `sam_model`, `sources`, `detectors`:
   первыми должны предлагаться Tagging Settings, Load SAM 3.1, SAM Text / Region
   Settings, YOLO Detector. В sources/detectors должны быть также Combine и Load
   Pipeline Config. Для проверки sources можно использовать Collect Evidence,
   чтобы не мешали взаимоисключающие SAM-входы теггера.
4. Протянуть связь от свободного входа на пустое место canvas. Должно открыться
   меню WDV3 с совместимыми нодами и пунктами полного поиска/штатного меню.
   Если используется Shift-поиск от связи, он также должен показывать рекомендации.
   Отмена Escape не должна оставлять новую ноду. Занятый вход нельзя молча заменить.
5. Для `sam_model` выбрать Load Pipeline Config: связь должна идти от выхода
   `sam_model`, а не options. В Inspect для `regions` выбрать Collect Evidence:
   связь должна идти от regions, а не evidence.
6. Протянуть связь от выхода `rules` Region Tag Rules: должны предлагаться YOLO
   Detector и SAM Text / Region Settings. От выхода `results` Apply Filters —
   Inspect и отдельные Merge Results · left / right. Выбранный вход должен совпадать.
7. У Results Viewer на `results_json` проверить предложения: они должны указывать
   results_json, не tags/txt_path. У Save Result проверить отдельный вход tags.
8. У Combine SAM Sources/Combine YOLO Detectors подключить первый источник и
   открыть рекомендации на следующем динамическом входе: список должен работать.
   Сохранить и повторно открыть workflow: существующие связи должны сохраниться,
   пункты меню не должны дублироваться.
9. При желании временно поставить штатный лимит Node Suggestions равным 1:
   основной производитель должен остаться первым, остальные — в «Все совместимые
   ноды WDV3». Затем вернуть прежнее значение. Проверить штатный поиск и
   стороннюю STRING-связь: они должны работать как раньше.

Сообщить, какие пункты прошли и где возникла проблема; при ошибке полезен текст
пункта меню или сообщения. Результат и фактические версии frontend/backend затем
добавляются в README приёмки. Снимки можно сохранить вручную при проверке.
