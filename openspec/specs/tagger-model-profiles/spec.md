# tagger-model-profiles Specification

## Purpose

Позволить использовать совместимые теггеры разных семейств с их собственным входным форматом во всех путях полного и регионального тегирования, сохраняя воспроизводимость и совместимость существующих настроек.

## Requirements

### Requirement: Выбор совместимого теггера
Система MUST предоставлять каталог совместимых timm multi-label теггеров SmilingWolf и AnimeTimm `dbv4-full`, учитывающий каталог организации и ranklist, и принимать полный Hugging Face repo ID. Старые aliases MUST сохранять прежние назначения. Выбор локальной модели MUST NOT требовать перечисления каталога через сеть.

#### Scenario: Старые настройки
- **WHEN** пользователь выбирает `vit`, `swinv2`, `convnext`, `big` или `bigvit`
- **THEN** выбирается прежний репозиторий SmilingWolf и сохраняются публичные результаты и пользовательские пороги

#### Scenario: Новый теггер
- **WHEN** пользователь выбирает `animetimm/convnextv2_huge.dbv4-full` либо `animetimm/caformer_b36.dbv4-full`
- **THEN** система загружает выбранную модель и её собственный словарь тегов для полного кадра и регионов

#### Scenario: Публикация вне встроенного списка
- **WHEN** задан полный repo ID совместимого теггера с поддерживаемыми метаданными
- **THEN** система использует его без добавления alias или ветвления по названию модели

#### Scenario: Порядок моделей в интерфейсе
- **WHEN** пользователь открывает список теггеров
- **THEN** модели ranklist идут по убыванию Macro F1@0.40, остальные — далее по убыванию даты публикации, а старые aliases и default `vit` сохраняются

### Requirement: Полный контракт входа из метаданных
Система MUST определять фактические `C,H,W`, порядок каналов, dtype, диапазон, нормализацию и последовательность padding/resize/crop из опубликованного inference-профиля выбранного теггера. Размер MUST NOT выводиться из имени архитектуры или общей константы. Отсутствующий, противоречивый либо неподдерживаемый профиль MUST вызывать понятную ошибку вместо универсального fallback.

#### Scenario: Разные входные размеры
- **WHEN** одно изображение подготавливается для `animetimm/convnextv2_huge.dbv4-full` и затем `animetimm/caformer_b36.dbv4-full`
- **THEN** входы модели имеют соответственно `[N,3,512,512]` и `[N,3,384,384]` с preprocessing выбранной модели

#### Scenario: Имя архитектуры не определяет размер
- **WHEN** профиль `animetimm/vit_base_patch16_224.dbv4-full` задаёт вход 448×448
- **THEN** система использует 448×448, несмотря на `224` в названии

#### Scenario: Полная форма
- **WHEN** поддерживаемый профиль задаёт разные высоту и ширину
- **THEN** система сохраняет обе оси и передаёт `[N,C,H,W]` без сведения формы к одному числу

#### Scenario: Ошибка профиля
- **WHEN** у AnimeTimm отсутствует обязательный inference-профиль либо профиль содержит неизвестную операцию
- **THEN** ошибка указывает repo ID, файл и проблему до запуска инференса без подстановки настроек WD

### Requirement: Единая подготовка пикселей
Полный кадр, YOLO/SAM-регионы и повторное тегирование MUST использовать один preprocessing выбранной модели. Цветовые преобразования и нормализация MUST выполняться ровно один раз в порядке профиля. Модельный resize MUST NOT менять исходную геометрию и сохранённые вырезки. RGBA MUST преобразовываться согласованно с профилем.

#### Scenario: Различие RGB и BGR
- **WHEN** цветная контрольная картинка поступает в WD и AnimeTimm
- **THEN** WD получает прежний BGR-профиль, AnimeTimm получает опубликованный RGB-профиль без дополнительного переворота каналов после нормализации

#### Scenario: Один кадр разными путями
- **WHEN** одинаковые пиксели подготавливаются как полный кадр и как регион в notebook и ComfyUI
- **THEN** тензоры совпадают при одинаковом профиле, а bbox и маски остаются в координатах исходника

### Requirement: Комплект ресурсов и локальная загрузка
Система MUST загружать и сохранять веса, конфигурацию, словарь и обязательные метаданные preprocessing как один совместимый комплект. Полный локальный комплект MUST работать без сети. При отключённом скачивании отсутствующие файлы MUST перечисляться без сетевых запросов; ошибки доступа MUST отличаться от отсутствия необязательного файла.

#### Scenario: Offline AnimeTimm
- **WHEN** все ресурсы AnimeTimm сохранены локально и скачивание выключено
- **THEN** модель и preprocessing загружаются без обращений к Hugging Face

#### Scenario: Gated-репозиторий
- **WHEN** скачивание разрешено, но Hugging Face запрещает доступ к обязательному файлу
- **THEN** система сообщает о необходимости авторизации или принятия условий для данного repo ID и не продолжает с неполным комплектом

#### Scenario: Изоляция репозиториев
- **WHEN** два выбранных repo ID имеют одинаковое имя модели после `/`
- **THEN** их файлы не смешиваются и локальный кэш однозначно связывает комплект с полным repo ID

### Requirement: Проверка входа и словаря
Перед передачей в модель система MUST проверять форму и dtype тензора согласно профилю. Выход MUST согласовываться с числом и порядком строк собственного словаря модели; категории MUST определяться по словарю. Пользовательские общие и региональные пороги MUST сохранять приоритет без автоматического применения опубликованных порогов тегов.

#### Scenario: Несовместимый словарь
- **WHEN** число выходных оценок отличается от числа строк `selected_tags.csv`
- **THEN** система выдаёт ошибку несовместимости модели и словаря вместо усечения через zip

#### Scenario: Дополнительные поля CSV
- **WHEN** CSV содержит `best_threshold` и совместимые `name/category`
- **THEN** порядок и категории сохраняются, а принятие тегов использует явно выбранные пользователем пороги

### Requirement: Воспроизводимость входного профиля
Происхождение результатов MUST включать полный repo ID, фактические `C,H,W`, цветовой порядок и fingerprint эффективного preprocessing. Изменение весов, словаря или профиля MUST исключать повторное использование несовместимых оценок, сохраняя возможность повторной фильтрации неизменных оценок без инференса.

#### Scenario: Метаданные изменились без замены весов
- **WHEN** меняется resize, нормализация или порядок каналов при прежних весах
- **THEN** идентичность теггера меняется, оценки пересчитываются и отчёт содержит новый профиль

#### Scenario: Изменился только порог
- **WHEN** модель, пиксели и preprocessing неизменны, а меняется порог фильтрации
- **THEN** существующий кэш исходных оценок может использоваться без повторного инференса
