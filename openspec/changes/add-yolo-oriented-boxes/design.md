# Предварительный дизайн

## Context
Scripts/detection.py читает result.boxes и box.xyxy, Scripts/regions.py создаёт осевую геометрию. Действующие требования сохраняют bbox xyxy и используют его для дочерних вырезок. OBB добавляется рядом с этим контрактом.

## Goals / Non-Goals
Сквозное сохранение ориентации от детектора до результата и просмотра. Выпрямление объектов, сегментация по OBB и изменение семантики родительства не включаются автоматически.

## Decisions
- Предлагаемое каноническое OBB-представление — четыре упорядоченные вершины в исходных пикселях, плюс тип геометрии. Альтернатива центр/размер/угол требует дополнительных соглашений об угле; адаптер может принимать её, явно выполняя преобразование.
- Сохранить отдельный осевой bbox для совместимости. Он не заменяет точную OBB.
- Предлагаемый первый режим тегирования и дочернего поиска — охватывающая осевая вырезка. Это сохраняет существующий контракт каскада. Выпрямленная вырезка потребует отдельного согласования и полного обратного преобразования.
- В экспорт, evidence, идентичность кэша и viewer включить тип и ориентированную геометрию; одинаковый осевой bbox не доказывает одинаковую OBB.
- За границей кадра хранить исходные вершины отдельно от видимой части/вырезки. Нормализованные исходные вершины могут выходить за [0,1]; нельзя зажимать каждую вершину, искажая рамку. Относительные границы в [0,1] гарантируются только геометрии внутри кадра.

## Risks / Trade-offs
- Различия соглашений моделей об угле → явное преобразование и тесты известных рамок.
- Осевая вырезка содержит фон → документировать режим; решение о выпрямлении отложено.
- Потеря ориентации в старых потребителях → сохранение OBB в полном результате и явно обозначенная осевая проекция для совместимости.

## Migration Plan
Расширить схему геометрии с чтением прежних записей как осевых. Согласовать изменения с хранением результатов и экспортом координат. Проверять оба типа детекторов в одном пайплайне.

## Open Questions
До реализации выбрать поддерживаемые модели/версии и подтвердить режим вырезки. Проверить API выбранной версии библиотеки по официальной документации на этапе реализации; этот план не фиксирует непроверенные детали внешнего API.
