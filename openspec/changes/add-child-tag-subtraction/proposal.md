# Proposal

## Why

Отдельные дочерние области уже могут сохранять свои теги либо передавать их родителю. Для пространственной разметки нужен обратный вариант: оставить детали у ребёнка и убрать совпадающие теги из его родителя без глобального запрета этих тегов.

## What Changes

- Добавить третий режим `subtract_from_parent` в Region Tag Rules рядом с separate/merge_to_parent.
- Вычитать принятые general/character дочернего итогового локального набора из соответствующей категории непосредственного родителя, сохраняя ребёнка отдельным.
- Объединять удаления всех детей одного родителя; выполнять после сбора дочерних вкладов, независимо от порядка соседних ветвей.
- Сохранять raw, собственные входные теги, геометрию и причины с идентификаторами родителя/детей; повтор маршрутизации воспроизводим.
- Поддержать Tag Image / Regions, Tag Folder, Collect Evidence, сохранение конфигов, Inspect и общий merge без новой обязательной ноды.
- Добавить комментированный демонстрационный workflow с ожидаемыми локальными наборами и автоматической проверкой.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `regional-tag-optimization`: вычитание дочерних тегов из родительского агрегата.
- `comfyui-regional-workflows`: выбор режима, объяснение результата и демонстрация каскада.

## Impact

Scripts/cascade.py, типы и нормализация маршрутов, comfy_cascade_tags.py, Region Tag Rules, preflight/frontend-восстановление, конфиги, Inspect, examples и audit. Не входят удаление из соседних родителей/полного кадра, глобальный blacklist, новые модели и переработка сохранения. Старые defaults separate сохраняются.
