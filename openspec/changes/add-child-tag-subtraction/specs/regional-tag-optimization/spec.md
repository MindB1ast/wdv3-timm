# Spec Delta

## ADDED Requirements

### Requirement: Вычитание дочерних тегов из родителя
Режим subtract_from_parent MUST сохранять ребёнка отдельно и удалять его принятые general/character-теги из тех же категорий итогового набора непосредственного родителя. Raw, ratings, геометрия и собственный входной набор MUST сохраняться. Сравнение MUST использовать полные канонические имена.

#### Scenario: Лицо и человек
- **WHEN** родитель имеет shirt, blue_eyes, open_mouth, а ребёнок имеет blue_eyes, open_mouth и выбран subtract_from_parent
- **THEN** итоговый родитель содержит shirt, ребёнок сохраняет оба своих тега, а raw родителя остаётся прежним

#### Scenario: Отсечённый тег и другой родитель
- **WHEN** blue_eyes ребёнка не прошёл его фильтры либо принадлежит ребёнку другого родителя
- **THEN** этот ребёнок не удаляет blue_eyes из рассматриваемого родителя

### Requirement: Детерминированное вычитание в каскаде
Система MUST вычитать объединение принятых дочерних итоговых наборов после их локальной/агрегатной обработки и добавления merge_to_parent-вкладов в родителя, до его агрегатной обработки. Результат MUST быть независим от порядка соседей. Повтор маршрутизации MUST начинаться с собственных принятых наборов.

#### Scenario: Смешанные маршруты
- **WHEN** один ребёнок добавляет blue_eyes родителю, а другой вычитает blue_eyes
- **THEN** blue_eyes отсутствует в итоговом родителе независимо от порядка детей; повтор маршрутизации даёт тот же результат

#### Scenario: Три уровня
- **WHEN** у ребёнка есть собственные дети
- **THEN** вычитание из его родителя использует уже обработанный итоговый набор ребёнка, а не неограниченный набор всех потомков

### Requirement: Объяснимость и общий caption
Каждое фактическое удаление MUST сохранять категорию, исходный score, ключ родителя и все дочерние свидетельства. Несработавшие удаления MUST NOT регистрироваться как фактические. Отдельный дочерний набор MUST участвовать в общем merge по прежним политикам переноса.

#### Scenario: Удаление не равно глобальному запрету
- **WHEN** blue_eyes удалён из родителя и разрешён к переносу из ребёнка
- **THEN** общий caption может содержать blue_eyes из ребёнка, а история показывает удаление только родительского вклада
