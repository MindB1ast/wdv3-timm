# Spec Delta

## ADDED Requirements

### Requirement: Выбор вычитания на дочернем источнике
Region Tag Rules MUST предоставлять subtract_from_parent рядом с separate/merge_to_parent. Настройка MUST относиться к выходу этой ступени в её родителя, переноситься через workflow/API/конфиги и работать в Tag Image / Regions, Tag Folder и Collect Evidence без отдельной ноды маршрутизации.

#### Scenario: Подключение нод
- **WHEN** правила лица с subtract_from_parent подключены к детектору лица, а его detectors подключены к child_detectors правил человека
- **THEN** результат лица вычитается только из человека, внутри которого найдено лицо

### Requirement: Совместимость и просмотр режима
Старые графы MUST сохранять прежние separate/merge_to_parent и defaults пустых значений. Корневая ступень с subtract_from_parent MUST отклоняться до моделей. Inspect и results_json MUST показывать собственные/итоговые теги и все причины вычитания с родительскими и дочерними ключами.

#### Scenario: Старый граф и недопустимый корень
- **WHEN** открывается старый граф с пустым маршрутом либо новый граф с subtract_from_parent на корне
- **THEN** первый использует separate, а второй отклоняется с понятной ошибкой

### Requirement: Демонстрация маршрутов тегов
Система MUST иметь комментированный workflow человека и лица с вариантами separate, merge_to_parent и subtract_from_parent, ожидаемыми локальными результатами и автоматической проверкой. Демонстрация MUST обходиться без лишних служебных нод.

#### Scenario: Сравнение вариантов
- **WHEN** выполняются три варианта на фиксированных исходных оценках
- **THEN** демонстрируются неизменный родитель, дополнение родителя и вычитание из родителя; сохраняется привязка каждого ребёнка
