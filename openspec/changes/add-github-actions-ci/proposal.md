# Proposal

## Why

Регрессии фильтрации и сохранения сейчас запускаются вручную. Нужна автоматическая проверка каждого pull request и push в `main`, не зависящая от локального ComfyUI или моделей.

## What Changes

- Добавить GitHub Actions с двумя проверками: Python-регрессии без весов и валидация основных OpenSpec-спецификаций.
- В Python-проверку включить ранее проверенный набор тестов фильтров, каскада, постобработки и экспорта, включая сохранённые эталоны и согласованность демонстрационного workflow с manifest.
- Документировать эквивалентный локальный запуск и отдельно указать, какие реальные модельные прогоны остаются ручными.

## Capabilities

Продуктовые требования не меняются: CI автоматизирует проверку существующего поведения.

## Impact

Новый workflow в `.github/workflows/`, документация `audit/README.md` и `.gitattributes` для точного воспроизведения двух существующих SHA-256 эталонов в checkout. Не меняются рабочие ноды, данные эталонов, настройки защиты веток и права репозитория; ревью-агент и GPU CI не входят в change.
