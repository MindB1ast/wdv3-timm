# Spec Delta

## ADDED Requirements

### Requirement: Настройки подготовки в Region Tag Rules
Region Tag Rules MUST иметь явное включение нового блока подготовки, padding_unit=px/percent, padding_value и единый background_color. Настройки MUST применяться независимо к YOLO/SAM-источнику в Tag Image / Regions, Tag Folder и Collect Evidence и сохраняться в workflow/config/API.

#### Scenario: Независимые источники
- **WHEN** правила лица задают 15%, а правила человека 8 px
- **THEN** каждый WD-вход подготовлен со своими параметрами, включая дочерние ступени

### Requirement: Совместимость прежнего padding
Без включения нового блока система MUST сохранять прежние пиксели вырезок, SAM padding_px и фон. При включении блока новые настройки MUST иметь явный приоритет над legacy padding_px, отображённый в подсказках; неверные unit/value/color MUST отклоняться до моделей.

#### Scenario: Старый workflow
- **WHEN** открывается workflow без новых полей с SAM padding_px=12
- **THEN** прежний способ подготовки и значения продолжают действовать

### Requirement: Просмотр фактического WD-входа
Inspect и экспорт отчёта MUST показывать фактическую подготовленную вырезку до model resize отдельно от исходной области/маски. Метаданные MUST содержать исходный bbox, целевой размер, фактическое окно, перенос и искусственные поля с RGB-цветом.

#### Scenario: Проверка фона
- **WHEN** пользователь открывает SAM-регион с заполнением
- **THEN** он видит именно пиксели, поданные на preprocessing WD, и может настроить обычные региональные фильтры по полученным тегам

### Requirement: Демонстрация padding
Система MUST поставлять комментированные workflows для YOLO/SAM, px/percent, границ и слишком большого окна с ожидаемыми размерами/цветами и автоматическими проверками. Обязательный дополнительный служебный граф MUST NOT требоваться для обычного применения.

#### Scenario: Воспроизводимый пример
- **WHEN** запускается демонстрация на фиксированном изображении
- **THEN** проверяются размер и пиксели WD-входа, общий SAM-цвет и неизменность исходной маски; изменение логики нарушает проверку
