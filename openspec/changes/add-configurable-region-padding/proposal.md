# Proposal

## Why

Региональная модель реагирует на контекст вокруг найденной области и искусственный фон. Нужны настраиваемые px/% отступы и единый цвет фона SAM, с переносом отступа у края вместо потери контекста или преждевременного заполнения.

## What Changes

- Добавить в Region Tag Rules блок подготовки WD-вырезки: padding_unit=px/percent, padding_value, background_color.
- Расширять bbox на заданную величину с каждой стороны; при пересечении края сдвигать окно к доступным пикселям, сохраняя целевой размер.
- Если целевой размер больше изображения, использовать все доступные пиксели по этой оси, а остаток заполнить выбранным цветом.
- В SAM mask использовать один цвет вне видимой маски и для искусственного padding; сохранять существующую семантику расширения видимой маски реальным контекстом.
- Показывать фактический WD-вход и параметры подготовки в Inspect, сохранять их в workflow/config/результате; оставить ручную фильтрацию фоновых тегов без автоматических запретов.
- Поддержать YOLO/SAM, плоские и каскадные графы, одиночный IMAGE и Tag Folder; добавить комментированные демонстрации с ожидаемыми результатами.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `regional-tag-optimization`: подготовка вырезок с переносом отступа и единым цветом заполнения.
- `comfyui-regional-workflows`: параметры подготовки в Region Tag Rules, просмотр WD-входа, совместимость конфигов.

## Impact

Scripts/regions.py, RegionViewConfig/DetectorConfig/cascade plan, comfy_config.py, comfy_processing.py, comfy_evidence.py, comfy_cascade.py, UI/preflight/frontend, Inspect/reports, examples и audit. Исходные bbox/маски не меняются; дочерняя детекция использует исходный bbox родителя без нового padding. Старые графы без нового блока сохраняют прежние пиксели и defaults, включая SAM padding_px. Переработка хранения результатов и subtract_from_parent находятся в отдельных changes.
