# Design

## Context

Буквальные подсказки объявлены в схеме `WDRegionRules`; `regex_inputs` обслуживает и эту ноду, и глобальное поле удаления в `Tagging Settings`. Заметки на холсте не являются источником подсказок при наведении.

## Goals / Non-Goals

Обновить только тексты, которые отдаёт схема `WDV3RegionRules`, сохранив общие пояснения синтаксиса. Не менять глобальное удаление, поведение существующих правил и сохранённые графы.

## Decisions

- Редактировать строки подсказок там, где они заданы, а не дублировать их во frontend. Глобальную ветку в `regex_inputs` оставить без изменений.
- Для близких по эффекту правил явно указать, что меняется: собственные теги региона, вклад полного кадра или вклад регионального источника. Сохранить внутреннее имя `exclude_from_region_regex` и его текущую подпись.

## Risks / Trade-offs

Длинные подсказки хуже читаются при наведении. Для каждого поля достаточно короткого назначения и одного примера; синтаксис остаётся в общем пояснении. После обновления кода ComfyUI потребуется заново загрузить схемы нод.
