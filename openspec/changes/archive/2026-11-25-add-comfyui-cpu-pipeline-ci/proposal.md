# Предложение

## Зачем

Быстрый CI проверяет сохранённые результаты, но не запускает реальные модели через сервер ComfyUI. Нужен пробный прогон на GitHub, чтобы проверить работоспособность графов и измерить время и пиковую память на CPU.

## Что меняется

- Добавить ручной GitHub Actions workflow с тремя сценариями: `yolo-cpu`, `sam-cpu` и `yolo-sam-cpu`. Позволить запускать каждый отдельно или все три через `all`.
- Запускать настоящий ComfyUI и реальные модели через локальный HTTP API, проверяя детекции, непустые маски и передачу региона YOLO в SAM.
- Исправить запуск SAM-воркера из каталога расширения, подключённого через символическую ссылку. Формат IPC и поведение модели не меняются.
- Оставить автоматический CI без изменений. Не переносить все девять исторических графов, не добавлять отдельную WD-проверку, GPU или секреты.

## Возможности

Новых и изменённых спецификаций нет: это тестовая инфраструктура, контракты рабочих нод остаются прежними.

## Влияние

Отдельный workflow, тестовые API-графы и конфигурация в `audit/`, документация запуска. Веса загружаются на раннер из проверенных публичных источников, не добавляются в Git.
