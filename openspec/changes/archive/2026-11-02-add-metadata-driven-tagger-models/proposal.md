# Proposal

## Why

Текущий выбор ограничен пятью WD v3 моделями, а общая предобработка принудительно переводит вход в BGR. Чтобы подключить новые теггеры SmilingWolf и AnimeTimm, нужен полный контракт входа каждой модели: размер, каналы, цвет, масштабирование и нормализация из её метаданных.

## What Changes

- Расширить выбор совместимыми timm multi-label теггерами SmilingWolf и семейством AnimeTimm `dbv4-full`, сверив каталог организации с ranklist; сохранить `vit`, `swinv2`, `convnext`, `big`, `bigvit`.
- Разрешить полный Hugging Face repo ID совместимой модели, чтобы новые публикации не требовали добавления очередного alias в код.
- Загружать полный inference-профиль из файлов выбранной модели: для AnimeTimm — `preprocess.json` (`test`), для WD — опубликованную конфигурацию timm и WD-профиль цветовых каналов. Не выводить размер из названия архитектуры.
- Использовать один профиль для полного кадра, YOLO/SAM-регионов, повторного тегирования, notebook и ComfyUI. Проверять `[C,H,W]` и `[N,C,H,W]`; `convnextv2_huge.dbv4-full` получает `[N,3,512,512]`, `caformer_b36.dbv4-full` — `[N,3,384,384]`.
- Сохранять профиль и его fingerprint в происхождении результатов и учитывать изменения метаданных в кэше; обеспечить локальную загрузку полного комплекта без сети и понятную диагностику gated-доступа.

## Capabilities

### New Capabilities

- `tagger-model-profiles`: выбор совместимых теггеров, загрузка их ресурсов и полная модельно-зависимая предобработка общего inference-пайплайна.

### Modified Capabilities

- `comfyui-regional-workflows`: требование «Явная загрузка моделей» расширяется общим каталогом, repo ID и отображением фактического входного профиля.

## Impact

Затронуты `Scripts/wdv3_timm.py`, `Scripts/model.py`, `Scripts/main.py`, `Scripts/tagging.py`, `Scripts/region_tagging.py`, контракты runtime, `comfy_nodes.py`, `comfy_evidence.py`, документация и проверки в `audit/`. Изменения не требуют изменения геометрии YOLO/SAM или формата двух списков `BatchTagging`. Возможна дополнительная зависимость для интерпретации AnimeTimm preprocessing; установка ComfyUI должна сохранить его PyTorch.

В объём входят timm/PyTorch multi-label модели с совместимым словарём `name/category`; ONNX-only старые релизы, VLM, single-label и другие словари не добавляются автоматически. Наличие модели в каталоге не отменяет условия доступа Hugging Face. Автоматическая смена пользовательских порогов на `best_threshold`, обучение и оценка улучшения качества тегов не входят в change.
