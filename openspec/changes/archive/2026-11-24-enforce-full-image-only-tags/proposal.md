# Proposal

## Why

Теги из full_image_only_tags сейчас могут оставаться в принятых тегах регионов и региональном JSON. Список должен исключать их из результата всех регионов и разрешать вклад только с полного кадра.

## What Changes

- Применять объединение настроенных списков и regex full_image_only_tags ко всем регионам кадра, до передачи тегов в каскаде и общего merge.
- Сохранять исходные оценки для диагностики и показывать причину исключения.
- Добавить исполняемый пример для полного кадра и каскада с merge_to_parent.

## Capabilities

### Modified Capabilities

- `regional-tag-optimization`: исключение тегов полного кадра из локальных наборов.
- `comfyui-regional-workflows`: согласованные просмотр, экспорт и объяснение исключения.

## Impact

Меняется смысл существующего поля в Region Tag Rules. Настройка в Tagging Settings и дополнительные правила отношений родителя и ребёнка отложены.
