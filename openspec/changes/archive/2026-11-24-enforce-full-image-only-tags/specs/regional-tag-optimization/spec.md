## MODIFIED Requirements

### Requirement: Независимые наборы принятых тегов до объединения
Система MUST предоставлять отдельную стадию после локальных порогов и правил допуска, до переноса тегов между источниками и общего merge. Полный кадр и каждый регион MUST сохранять отдельные принятые general/character-теги, исходные оценки, идентичность и геометрию. Операции этой стадии MUST NOT сравнивать теги разных наборов.

#### Scenario: Два персонажа
- **WHEN** два региона одного кадра независимо содержат `1girl`, и тег не зарезервирован за полным кадром и не запрещён другими правилами
- **THEN** оба локальных набора сохраняют `1girl`

#### Scenario: Разные источники описывают одежду
- **WHEN** полный кадр содержит `skirt`, а отдельный регион содержит только `black_skirt`
- **THEN** локальная очистка региона не удаляет `skirt` полного кадра; их последующее объединение использует отдельно заданные политики источников

## ADDED Requirements

### Requirement: Теги зарезервированы за полным кадром
Объединение эффективных full_image_only_tags и full_image_only_tags_regex всех источников MUST исключать совпадающие принятые теги из всех регионов кадра до их передачи по каскаду. Исходные оценки MUST сохраняться. В общем caption совпавший тег MUST поступать только из принятого набора полного кадра.

#### Scenario: Запрет у одного из источников
- **WHEN** у одного источника задан 1girl и этот тег распознан в нескольких регионах разных источников
- **THEN** принятые наборы и агрегаты всех регионов исключают 1girl; общий caption содержит его только при принятии на полном кадре
