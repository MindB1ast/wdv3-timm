# Design

## Context

Проверка full_image_only_tags сейчас применяется при общем объединении. Принятые теги локальных записей уже сформированы к этому моменту.

## Решение

Для кадра построить общий предикат из эффективных правил всех настроенных источников, включая источники без детекций. Объединить буквальные имена и regex через OR. Применить предикат к regional general/character после локальных правил и ручных добавлений, до локальных операций и маршрутизации. Сохранить причину в decisions и очистить соответствующие принятые теги, локальный текст и provenance. Исходные raw_scores, рейтинги и геометрия сохраняются. Агрегаты каскада используют очищенные наборы. Применение к полному кадру остаётся за обычными фильтрами кадра. При сборке caption входом для таких тегов может быть только принятый полный кадр.

Сохранить различие отсутствующего списка и явно пустого списка при построении эффективных правил. Отдельно проверить существующие встроенные композиционные значения и regex. Изменения правил применяются к готовым evidence без повторной детекции.
