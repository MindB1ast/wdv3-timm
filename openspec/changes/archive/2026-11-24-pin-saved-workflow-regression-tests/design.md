# Design

Перенести проверенные графы и эталоны в audit/fixtures. Сохранять без изменений небольшой TXT/JSON, для большого подробного JSON фиксировать SHA-256 канонического JSON. Для подробного JSON исключать только три значения download_missing, которые задаёт тестовый запуск. Внешние файлы изображений проверять по SHA-256, модели не скачивать.

Запускать сохранённые конфигурации через реальный API нод установленного ComfyUI без запуска GUI. Изменять на время теста только целевой каталог и разрешение скачивания. Сравнение точное, эталоны обновляются отдельно от запуска. Предусмотреть отдельное сравнение артефактов предыдущего прогона. Каждый сценарий сообщает свой результат и общий exit code.

Tag Folder читает хешированные копии изображений в temp; сохранять только в отдельный каталог и сравнивать полный рекурсивный список относительных путей. Проверить выключенную и включённую рекурсию отдельно.

Filters_test получает отдельный manifest с правилом и ожидаемым JSON для каждого сохранённого файла. Исходный workflow сохраняется отдельно от восстановленного многоветочного примера. Граф примера содержит один Collect Evidence и отдельные Region Tag Rules → YOLO → Apply Filters overrides → Save Compact JSON для каждого варианта. Конфигурации, восстановленные по имени/результату, помечаются в manifest, поскольку исторические значения всех запусков в workflow отсутствуют.

Однократно получить evidence через реальный Collect Evidence на хешированном исходном изображении и локальных моделях. Сохранить JSON-portable Bundle с исходными оценками в gzip-fixture с checksum. После получения оценок сравнить все 14 вариантов с неизменёнными пользовательскими эталонами. Обычный запуск регрессий читает fixture и исполняет реальные filter/merge/export без инференса. Смена фикстуры требует явной операции приёмки, обычный запуск не обновляет эталоны. Для каждой ошибки выводится отдельный FAIL, остальные варианты продолжают проверяться. Дополнительно фиксируются изменения собственных тегов регионов и caption относительно baseline по идентичности областей.

Новый набор хранится отдельно от оригинального workflow и 16 эталонов. Для одиночных источников повторно использовать закреплённые оценки `person`; для двух параллельных источников создать контролируемую фикстуру `person_A` и `person_B` на одних оценках с отдельными настройками и идентичностями. В демонстрации использовать две параллельные ноды с одинаковыми настройками детектора, но разными именами. Каждый сценарий получает человекочитаемое имя, совпадающее с основой имени выходного `.regions.json` и ключом в manifest.

Проверять полные и локальные наборы и caption отдельно; где одинаковый caption скрывает источник тега, проверять происхождение через данные результата. Для подтверждения полным кадром исключить его вклад в обеих сравниваемых ветках, оставив принятый тег полного кадра как подтверждение. Точное равенство порогу проверять без моделей на фиксированных оценках, не полагаться на округление значения в UI. Ожидания описывать явно, а не получать их автоматически из проверяемой реализации.
