# Proposal

## Why

Семь пользовательских графов успешно воспроизвели сохранённые результаты. Нужны неизменяемые эталоны и повторяемая команда для обнаружения регрессий.

## What Changes

- Зафиксировать семь графов с контрольными суммами исходных изображений и ожидаемыми TXT/JSON.
- Запускать графы с локальными моделями и отдельным каталогом вывода.
- Документировать отличие этих проверок от быстрых тестов и имеющиеся пробелы.

## Capabilities

### Modified Capabilities

- `comfyui-regional-workflows`: воспроизводимая проверка сохранённых графов.

Дополнение: зафиксировать сохранённый folder_tagging и рекурсивный вариант по существующим TXT.

Дополнение по пользовательским filters_test: зафиксировать 16 сохранённых компактных JSON, включая добавленные пороговые примеры, восстановить отдельные конфигурации по именам и последнему сохранённому workflow, проверяя воспроизведение каждого эталона. Создать один демонстрационный граф с независимыми подписанными ветками на общем evidence, сохранить исходные оценки для повторения без моделей и выдавать отдельный PASS/FAIL по каждому фильтру. Пороги проверяются при значении 1, остальные пороговые сценарии учитываются отдельно.

Расширить покрытие отдельным демонстрационным workflow на основе сохранённого `WDV3 Region Tag Rules Tests`: по нескольку тегов с разными исходами, явное сравнение похожих правил на двух источниках и проверка границ порогов. Имена новых сценариев, веток и JSON должны описывать проверяемое поведение. Пользовательский workflow и 16 исторических эталонов остаются неизменными.
