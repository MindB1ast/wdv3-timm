# Proposal

## Why

Независимые детекторы полного изображения не позволяют задать последовательность «найти человека → искать лицо только в его области → искать глаза только в области лица». Для детализации общего описания и будущей работы с отдельными объектами нужны вложенные вычисления с однозначной привязкой дочерних областей к родителям и управляемой передачей тегов вверх.

## What Changes

- Добавить настраиваемый конечный каскад YOLO/SAM-этапов: корневые этапы работают по полному изображению, дочерние — отдельно по каждой найденной области выбранного родительского этапа.
- Сохранять дерево вычисленных областей, устойчивые идентификаторы, связь с родителем и координаты bbox/масок в системе исходного изображения независимо от глубины.
- Поддержать полный набор обычных настроек YOLO/SAM и WD каждого этапа, включая применение собственной маски и заливку фона при WD-тегировании; настройки независимы, наследование от родителя в этот change не входит. Промежуточный этап можно использовать только для поиска дочерних областей без обязательного WD-тегирования этой ступени.
- Дочерний детектор получает прямоугольную область bounding box родителя из исходного изображения, без применения родительской SAM-маски, заливки фона или подготовки родительского WD-входа. Собственная маска дочерней области применяется к её WD-входу только по настройкам дочернего этапа.
- Для дочерней ветви явно выбирать `separate` — независимый набор тегов, либо `merge_to_parent` — дополнение тегов непосредственного родителя. При обоих режимах исходные дочерние оценки, геометрия и происхождение сохраняются.
- Применять локальные фильтры и операции над тегами к нужной области, затем передавать принятые теги снизу вверх без смешивания разных родителей и повторного вклада одной ветви.
- Добавить дочерний стек обычных YOLO/SAM в Region Tag Rules; там же выбирать separate/merge_to_parent. Дерево строится по подключениям автоматически, без Cascade Stage, ручных stage_id/parent_stage и отдельного Route. Обычные Tag Image / Regions, Tag Folder и Collect Evidence исполняют вложенность. Настройки и дерево переносятся через прежний Save/Load Pipeline Config; при отсутствии родителей дочерние детекторы не запускаются.
- Сохранить нынешний глобальный caption и прежние плоские workflow; новый отдельный формат объектных подписей не требуется.

## Capabilities

### New Capabilities

Нет: расширяются действующие контракты региональных вычислений и ComfyUI.

### Modified Capabilities

- `regional-tag-optimization`: каскадное получение областей, родительские привязки, преобразования координат и явная маршрутизация локальных тегов.
- `comfyui-regional-workflows`: сборка каскада, ноды исполнения/маршрутизации, проверка графа, просмотр дерева и перенос настроек.

## Impact

Затрагиваются геометрия и типы `Scripts/regions.py`/`Scripts/types.py`, детекция YOLO/SAM и подготовка вырезок, `comfy_evidence.py`, pipeline-ноды, правила объединения, конфиги, preflight, каталог подключений, Inspect/отчёты, примеры и тесты. Контракт локальных наборов тегов и операций из `add-scope-local-tag-redundancy` является зависимостью реализации. Условные операции из `add-conditional-tag-postprocessing` подключаются, если доступны, но не обязательны для каскада. Постоянное хранилище/агенты, автоматическое установление семантической принадлежности, tracking, межкадровые связи, новые модели и объектный формат caption остаются вне scope. Связь «найдено внутри вычисления родителя» не объявляется доказанной связью «является частью объекта».
