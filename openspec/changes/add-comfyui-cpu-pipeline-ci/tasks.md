# Задачи

## 1. Окружение и сценарии

- [x] 1.1 Зафиксировать совместимые ревизии ComfyUI, CPU-зависимостей и публичных весов YOLO и SAM 3.1 (и WD, только если нужен графам). Проверить чистую установку и загрузку без токена; записать ревизии, контрольные суммы и условия использования.
- [x] 1.2 Подготовить манифест, контрольный вход и три API-графа. Реализовать проверки класса и bbox для `yolo-cpu`, непустой полноразмерной маски для `sam-cpu`, связи и положения дочерней маски для `yolo-sam-cpu`. Покрыть отрицательными тестами пустую маску, неправильный размер и отсутствие родительской связи.

## 3. Первый прогон
