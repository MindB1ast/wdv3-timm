# Фидбек по задачам агентов

## Why

Нужно сохранять успешные и неуспешные попытки по разным задачам агентов, чтобы видеть нерешённые случаи и повторно использовать удачные способы решения.

## What Changes

- Ввести журнал попыток с задачей, агентом, изображением/объектом/регионом, результатом и свидетельствами.
- Сохранять, что пробовали и как получили результат либо почему не получили.
- Различать исход выполнения и оценку правильности; принимать последующие исправления фидбека.
- Дать выборку по типу задачи и исходу.

Статус: отложенный план, реализация не запрошена.

## Capabilities

### New Capabilities

- `agent-task-feedback`: журнал исходов и обратной связи по агентным задачам.

### Modified Capabilities

Нет.

## Impact

Новый журнал поверх будущих ролей поиска тегов, проверки описаний, получения и объединения тегов. Связи с add-danbooru-tag-discovery-agent, add-tag-description-review-agent и add-versioned-tag-knowledge. Реестр экспериментов regional-tag-optimization описывает оптимизацию профилей; этот журнал охватывает отдельные агентные задачи. Автоматическое обучение и изменение правил по фидбеку не входят.
