# Proposal

## Why

Сохранение результатов разрознено: Tag Folder и Save Result записывают TXT/JSON без масок, Export Report сохраняет связанные assets, а evidence предназначены для повторного расчёта. Нужен единый способ хранить и получать изображения, региональные теги и отдельные маски для подготовки обучающих данных, включая локальную БД без обязательного промежуточного импорта evidence.

## What Changes

- Ввести версионированный пакет результата: изображение, локальные и итоговые теги, регионы, родительские связи, отдельные SAM-маски, настройки и происхождение.
- Добавить необязательное сохранение/загрузку и поиск результатов в локальной SQLite, переиспользуя ArtifactStore и хранилище бинарных объектов; кэш расчётов остаётся отдельным по смыслу.
- Дать структурированный выход для сохранения из Tag Image / Regions и Tag Folder, не теряющий маски при преобразовании в строковый results_json; поддержать одиночное изображение, батч и папку.
- Согласовать запись файлов: TXT error/skip/append/overwrite; JSON и пакет региона error/skip/overwrite без неявного объединения геометрии. Настройки сохранения отделены от режима инференса.
- Добавить единый экспорт пакета с PNG-масками и JSON-манифестом, а также загрузку сохранённой версии без моделей. Итоговый merge необязателен для хранения локальных тегов.
- Сохранить старые выходы и defaults Save Result/Tag Folder; legacy overwrite отображается на общий контракт с явным отклонением противоречивых настроек.
- Для каждой новой ноды подготовить демонстрационный workflow и автоматическую проверку ожидаемых данных, включая обратную загрузку, ошибки и повторный запуск.

- Исправить Save Result: сохранение только TXT из tags не требует results_json; обязательность данных определяется выбранными форматами записи.

- Добавить отдельную ноду Save Region Results для компактного экспорта текущего results_json с выбором кадра, содержимого и режима записи.

- Первым этапом добавить файловый экспорт SAM-масок без Inspect и без зависимости от SQLite: прямой вход `results` в Export Report и опциональные отдельные маски в Save Compact JSON при подключении `results`. Для компактного экспорта сохранять бинарные PNG в размере исходного кадра и относительные ссылки в записях регионов рядом с тегами. Старые входы и поведение по умолчанию сохраняются.

## Capabilities

### New Capabilities

- `structured-result-storage`: локальный каталог версий результатов, связанных регионов/тегов/масок, загрузка и переносимый файловый экспорт.

### Modified Capabilities

- `comfyui-regional-workflows`: единый контракт сохранения, структурированные выходы тегирования и ноды записи/загрузки результатов.

## Impact

Затрагиваются Scripts/artifact_store.py, новое представление результата и каталог SQLite, comfy_processing.py, comfy_evidence.py, comfy_export.py, comfy_reports.py, UI/pipeline-ноды, configs/preflight, examples и audit. SQLite используется через стандартную библиотеку; внешний сервер не требуется. Не входят тренер моделей, конкретные COCO/YOLO training adapters, браузер БД, ручной редактор масок, переработка этапов фильтрации, автоматическое удаление старых версий и обязательная миграция старых файлов. Старый results_json не объявляется источником отсутствующих масок.
