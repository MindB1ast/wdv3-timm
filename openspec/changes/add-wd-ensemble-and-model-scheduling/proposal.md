# Proposal

## Why

Одна WD-модель ограничивает полноту кандидатов и не позволяет выбрать разные модели для общих тегов, персонажей и рейтингов. Одновременная загрузка всех детекторов и WD-моделей может исчерпать память, а безусловная последовательная работа оставляет неиспользованными доступные ресурсы.

## What Changes

- Добавить WD Tagger Ensemble с выходом `wd_model` для Tag Image / Regions, Tag Folder и Collect Evidence. Участники сохраняют собственный preprocessing; для каждого можно выбрать полный кадр и нужные региональные источники.
- Объединять исходные оценки по имени и категории до порогов. Поддержать максимум, взвешенное среднее и выбор модели отдельно для `general`, `character` и `ratings`.
- Добавить план вычислений с зависимостями детекции и WD, режимы `sequential`, `parallel`, `auto`, отдельные лимиты батчей и наблюдаемые события загрузки/выгрузки.
- В режиме экономии памяти по очереди рассчитать детекцию в пределах рабочего пакета, сохранить регионы, затем по очереди запустить WD-модели на выбранных областях. В параллельном режиме выполнять независимые задачи в пределах явно заданных ресурсов.
- Сохранять исходные оценки участников отдельно. Изменение весов, метода объединения и порядка планирования не требует повторного инференса при доступных совместимых оценках.
- Сохранить прежний workflow одной модели и дать комментированные исполняемые демонстрации для каждой новой ноды и режима.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `tagger-model-profiles`: совместимые ансамбли, объединение и происхождение оценок моделей.
- `comfyui-regional-workflows`: узлы конфигурации ансамбля, управляемый запуск детекторов и WD, переносимые настройки и демонстрации.

## Impact

Затронуты WD runtime и preprocessing, детекторные адаптеры и SAM workers, плоский и вложенный графы, постоянный кэш, настройки ComfyUI, конфиги, Inspect, examples и audit. Поддерживаются существующие способы привязки детекторов к стадиям, включая разные SAM-конфигурации в каскаде. Не входят межсерверное выполнение, обучение или калибровка моделей, каскад с ранним выходом по уверенности, веса по отдельным тегам и переработка топологии плоских SAM-источников.
