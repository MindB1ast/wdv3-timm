# Spec Delta

## ADDED Requirements

### Requirement: Ансамбль моделей тегирования
Ансамбль MUST запускать участников с их preprocessing и объединять raw scores по категории и каноническому имени до фильтров. Каждый участник MUST иметь явный выбор полного кадра и региональных источников. В результате MUST сохраняться происхождение оценок.

#### Scenario: Разные словари и области
- **WHEN** A тегирует полный кадр и лицо, а B только лицо и имеет дополнительный тег
- **THEN** B не запускается на полном кадре, а его тег может появиться у лица без подстановки нуля за отсутствующий тег A

### Requirement: Стратегия оценок по категории
Для general, character и ratings ансамбль MUST поддерживать max, weighted_mean и выбор одного участника. Веса MUST быть конечными и неотрицательными; среднее MUST нормализоваться по доступным ненулевым весам для данного тега. Отсутствующая оценка MUST оставаться отсутствующей.

#### Scenario: Полнота и усреднение
- **WHEN** оценки тега равны 0.62 и 0.18, а порог равен 0.4
- **THEN** max оставляет тег, а среднее с равными весами даёт 0.4 и строгий порог его отсекает

#### Scenario: Выбор рейтингов
- **WHEN** для ratings выбрана модель B
- **THEN** её оценки остаются отдельно в ratings с указанием источника; форматирование caption сохраняет прежнее поведение

### Requirement: Независимость исходных оценок от политики ансамбля
Исходные оценки MUST храниться по участнику, входу и региону. При доступных оценках изменение стратегии, весов или режима планирования MUST пересобирать результат без моделей. Замена одного участника MUST NOT инвалидировать оценки остальных при прежних входах.

#### Scenario: Пересборка без моделей
- **WHEN** пользователь меняет веса у группы с полным кэшем
- **THEN** объединённые оценки пересчитаны, а число вызовов моделей равно нулю
