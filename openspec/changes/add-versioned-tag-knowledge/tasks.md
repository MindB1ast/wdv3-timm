# Предварительные задачи

Отложенный change: реализация не запрошена. Список фиксирует будущие блоки работ, а не утверждённый технический план. По просьбе пользователя детали уточняются ближе к реализации; после пункта 1.1 последующие задачи необходимо пересмотреть до выполнения.

## 1. Уточнение перед реализацией

- [ ] 1.1 Согласовать с пользователем методику поиска, критерий отсутствия подходящего результата, формат хранения и политику обновления; результат — уточнённые design/specs/tasks без неявных решений.

## 2. Записи знаний

- [ ] 2.1 Реализовать согласованный контракт записи и историю версий; проверить сохранение всех полей и доступ к старой версии после обновления, документировать формат.
- [ ] 2.2 Реализовать направленные импликации и отдельные связи сходства; тестом подтвердить, что обратный обход не назначает частный тег автоматически.

## 3. RAG и потребители

- [ ] 3.1 Реализовать согласованный поиск и выдачу контекста с версиями и источниками; проверить найденный ответ, отсутствие ответа и ошибку на фиксированном наборе, документировать вызов.
- [ ] 3.2 Проверить передачу контекста этапам получения и объединения тегов через согласованные интерфейсы; пример должен сохранять принадлежность области и версии знаний.
