# Предварительный дизайн

## Context

Текущий проект даёт региональные теги и геометрию; целевая regional-tag-optimization предусматривает VLM и происхождение текстов. Конкретный исследователь Danbooru — новая роль. Контракт знаний задан соседним change add-versioned-tag-knowledge.

## Goals / Non-Goals

Цель — ограниченное исследование конкретной недоописанной области. Не входит реализация общего оптимизатора, обучение VLM или утверждение заранее выбранного тега для пользовательского примера.

## Decisions

- Вход: оригинал, область, известные теги, описание детали и исход локального поиска. Альтернатива — один плоский список тегов — теряет принадлежность предмету.
- Разделить адаптеры инструментов и логику субагента: описания, импликации, поиск постов, изображения и теги; web search подключается отдельно. Конкретные API здесь не утверждаются.
- VLM сопоставляет кандидатов с оригиналом и примерами. Текстовое совпадение или совместная встречаемость используются для поиска, но недостаточны для принятия.
- Результат содержит кандидатов, основания и исход выполнения. Запись в базу проходит отдельную политику принятия, а не превращает любой поисковый результат в факт.

## Risks / Trade-offs

- Тег на найденном изображении относится к другому объекту → проверка области и значения тега.
- Неполный поиск, сбой сети, лимит запросов → отдельные статусы и сохранение уже найденных свидетельств.
- Недостоверное имя тега → проверка существования и описания через источник перед подтверждением.

## Migration Plan

Подключать как новый этап после локального поиска. При отключении сохраняется исходный результат с нерешённым запросом. Испытания инструментов сначала на фиксированных ответах; сетевые проверки отделены от воспроизводимых тестов.

## Open Questions

До реализации уточнить методику поиска вместе с пользователем, инструменты Danbooru и веб-поиска, VLM, бюджет, критерий достаточности свидетельств, политику принятия новых записей и границу автоматического вызова. Пример перчаток описывает задачу исследования; существование и применимость конкретного названия здесь не проверялись. План предварительный, задачи подлежат уточнению.
