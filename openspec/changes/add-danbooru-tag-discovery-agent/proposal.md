# Субагент поиска недостающих тегов

## Why

Когда теггер и локальная база не дают подходящего конкретного тега, требуется исследовать словарь и визуальные примеры Danbooru.

## What Changes

- Добавить субагента с VLM и инструментами чтения Danbooru; предусмотреть подключаемый поиск в интернете.
- Искать по описаниям тегов, конкретизациям через импликации и сочетаниям известных признаков; изучать изображения и их теги.
- Сопоставлять найденные кандидаты с исходной областью, возвращать обоснование либо отсутствие подтверждённого ответа.
- Готовить сведения для пополнения versioned-tag-knowledge с происхождением; правила принятия уточнить отдельно.

Это отложенное направление разработки. Текущий запрос оформляет планы; реализация не начата. Общая оптимизация пайплайна получения тегов и этапа объединения — контекст будущего оркестратора, а не дополнительные задачи этого change.

## Capabilities

### New Capabilities

- `danbooru-tag-discovery`: Субагент поиска недостающих тегов.

### Modified Capabilities

Нет. Новая возможность дополняет целевую regional-tag-optimization, сохраняя её требования к областям, исходным свидетельствам и происхождению.

## Impact

Зависит от контракта add-versioned-tag-knowledge и будущей агентной оркестрации. Потребуются адаптер Danbooru, VLM и необязательный web search. Точные API, модели, стратегия запросов и лимиты не выбраны. Текущие WD-оценки не подменяются результатом поиска.

Не входят обучение моделей, реализация общего оптимизатора и изменение текущих тестов основных функций. Перед реализацией нужно уточнить открытые решения в design.md.
