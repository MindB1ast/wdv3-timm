# Предварительные задачи

Отложенный change: реализация не запрошена. Список фиксирует будущие блоки работ, а не утверждённый технический план. По просьбе пользователя детали уточняются ближе к реализации; после пункта 1.1 последующие задачи необходимо пересмотреть до выполнения.

## 1. Уточнение перед реализацией

- [ ] 1.1 Согласовать стратегию поиска, адаптеры, VLM, бюджет и политику принятия записи; результат — уточнённые design/specs/tasks и совместимый контракт базы знаний.

## 2. Инструменты и исследование

- [ ] 2.1 Реализовать чтение описаний, импликаций и поиск изображений с тегами в Danbooru, подключение web search; проверить фиксированными ответами успех, пустую выдачу и сбой, документировать настройки.
- [ ] 2.2 Реализовать VLM-проверку кандидатов по исходной области и примерам; проверить сценарий перчаток и ложного кандидата, относящегося к другому объекту, документировать входы.

## 3. Результат и интеграция

- [ ] 3.1 Реализовать отчёт с источниками, кандидатами и исходом выполнения; тестами различить отсутствие ответа, неопределённость, сбой и исчерпание бюджета.
- [ ] 3.2 Реализовать передачу кандидата записи по согласованной политике; проверить путь от отсутствия локального ответа до нового знания без изменения исходных WD-оценок и документировать пример.
