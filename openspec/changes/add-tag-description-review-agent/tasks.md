# Предварительные задачи

Отложенный change: реализация не запрошена. Список фиксирует будущие блоки работ, а не утверждённый технический план. По просьбе пользователя детали уточняются ближе к реализации; после пункта 1.1 последующие задачи необходимо пересмотреть до выполнения.

## 1. Уточнение перед реализацией

- [ ] 1.1 Согласовать модели, бюджет, контрольный набор и эксперимент для разделения пропусков и ошибок генератора; результат — уточнённые design/specs/tasks с критериями оценки.

## 2. Визуальная проверка

- [ ] 2.1 Реализовать прямую VLM-проверку оригинала и описания; проверить пропуск, противоречие и ошибку принадлежности объекта на контрольных примерах, документировать контракт.
- [ ] 2.2 Реализовать генерацию по тегам с сохранением фактического prompt и параметров; проверить прослеживаемость преобразования и обработку отказа генератора, документировать настройки.

## 3. Причины и обратная связь

- [ ] 3.1 Реализовать согласованную процедуру сравнения и классификации причин; контрольным экспериментом проверить случай уже указанного, но не сгенерированного признака и допустимый неопределённый исход.
- [ ] 3.2 Реализовать версионированный отчёт и передачу замечаний этапам получения/объединения; интеграционным примером проверить запрос недостающего названия без автоматической подмены исходного описания.
