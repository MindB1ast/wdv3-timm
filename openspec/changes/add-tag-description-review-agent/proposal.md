# Субагент проверки согласованности и полноты описаний

## Why

Даже после получения и объединения тегов описание может пропускать детали или противоречить изображению. Требуется отдельная визуальная проверка с учётом ограничений генератора.

## What Changes

- Добавить VLM-субагента для проверки тегов и объединённого описания по оригиналу и областям.
- Предусмотреть генерацию изображения по проверяемым тегам и сравнение с оригиналом как основной исследуемый способ проверки полноты.
- Различать неполноту описания, ограничение генератора и неустановленную причину расхождения.
- Сохранять отчёт, свидетельства и воспроизводимые параметры проверки.

Это отложенное направление разработки. Текущий запрос оформляет планы; реализация не начата. Общая оптимизация пайплайна получения тегов и этапа объединения — контекст будущего оркестратора, а не дополнительные задачи этого change.

## Capabilities

### New Capabilities

- `tag-description-review`: Субагент проверки согласованности и полноты описаний.

### Modified Capabilities

Нет. Новая возможность дополняет целевую regional-tag-optimization, сохраняя её требования к областям, исходным свидетельствам и происхождению.

## Impact

Потребуются адаптер генерации, VLM и контракты результатов будущих этапов тегирования/объединения. Отчёт может направлять поиск через add-danbooru-tag-discovery-agent и использовать add-versioned-tag-knowledge. Выбор моделей и методика атрибуции ошибок отложены.

Не входят обучение моделей, реализация общего оптимизатора и изменение текущих тестов основных функций. Перед реализацией нужно уточнить открытые решения в design.md.
