## Purpose

Проверять согласованность и полноту тегов и объединённых описаний по исходному изображению, используя визуальный анализ и генерацию с учётом ограничений моделей.

## ADDED Requirements

### Requirement: Проверка согласованности с оригиналом
VLM-субагент MUST проверять теги и объединённое описание относительно оригинала и целевых областей. Отчёт MUST различать противоречие, пропуск и неопределённость и связывать замечание с соответствующим объектом или областью.

#### Scenario: Признаки разных объектов
- **WHEN** объединённое описание приписывает одному объекту несовместимые признаки из разных областей
- **THEN** отчёт указывает конфликт принадлежности и визуальные свидетельства

### Requirement: Генеративная проверка полноты
Субагент MUST поддерживать генерацию изображения по проверяемым тегам и сравнение результата с оригиналом с помощью VLM. Он MUST сохранять исходные теги, фактически переданный prompt и параметры генерации; преобразование тегов в prompt MUST быть прослеживаемым.

#### Scenario: Сравнение с генерацией
- **WHEN** запущена проверка полноты через генерацию
- **THEN** отчёт содержит ссылки на оригинал и результат генерации, перечень существенных расхождений и версии использованных моделей

### Requirement: Разделение причин расхождения
Расхождение MUST NOT автоматически означать неполноту описания. Субагент MUST различать предполагаемый пропуск в описании, ограничение генератора и неустановленную причину, указывая основания вывода. Неустановленная причина MUST NOT превращаться в подтверждённую ошибку тегирования.

#### Scenario: Генератор игнорирует указанный признак
- **WHEN** признак виден на оригинале и явно присутствует в prompt, но отсутствует в генерации
- **THEN** это не объявляется пропущенным тегом; отчёт рассматривает ограничение генератора либо неопределённость

#### Scenario: Деталь отсутствует в описании
- **WHEN** деталь видна на оригинале, отсутствует в описании и не воспроизведена генератором
- **THEN** отчёт фиксирует предполагаемый пропуск с опорой на оригинал и текст, а не только на различие изображений

### Requirement: Прослеживаемость и ограниченность проверки
Отчёт MUST сохранять версию описания, VLM, генератора, prompts, параметры и доступные seeds, а также выполненные проверки и ограничения. Ошибка или незавершённость проверки MUST NOT означать подтверждённую полноту.

#### Scenario: Генерация недоступна
- **WHEN** генератор завершился ошибкой
- **THEN** отчёт отмечает невыполненную генеративную проверку отдельно от доступного прямого анализа оригинала

### Requirement: Обратная связь этапам описания
Субагент MUST возвращать замечания и предложения для этапов получения и объединения тегов, сохраняя исходный результат. Предположение проверяющего MUST отличаться от принятого исправления.

#### Scenario: Требуется конкретное название
- **WHEN** проверка обнаружила неописанную деталь без известного тега
- **THEN** результат позволяет запросить поиск по этой области и признакам без выдуманного конкретного тега
