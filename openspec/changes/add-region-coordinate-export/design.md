# Предварительный дизайн

## Context
Scripts/regions.py использует canonical_pixels_half_open_xyxy и сохраняет image_size; rectangle_geometry округляет/ограничивает осевой bbox. План structured-result-storage уже предусматривает версии пакета, bbox и размеры изображения.

## Goals / Non-Goals
Настраиваемое представление сохраняемой геометрии с обратной загрузкой. Изменение координат инференса и обучение моделей не входят.

## Decisions
- Сохранить внутренний пиксельный xyxy и преобразовывать на границе сохранения/загрузки. Альтернатива — заменить все внутренние координаты нормализованными — затрагивает каскад и маски без необходимости.
- Для x использовать W, для y H, а не W−1/H−1: правые/нижние half-open границы полного кадра превращаются в 1.
- Сохранять единицы и размеры явно; запрещено распознавать формат лишь по диапазону чисел.
- Предварительно сохранить пиксели режимом по умолчанию. Связать параметры экспорта с существующим change хранения.
- OBB в соседнем change расширяет геометрию вершинами. Их нормализация по осям обратима, но на неквадратном кадре нормализованный четырёхугольник не обязан выглядеть прямоугольным.

## Risks / Trade-offs
- Потеря точности → документированная точность сериализации и тест обратного преобразования.
- EXIF и вложенные вырезки → использовать канонический исходный кадр и сохранённые преобразования.
- Несовместимые старые записи → читать только по известным контрактам версии, неизвестные форматы диагностировать.

## Migration Plan
Добавить версию представления и новые настройки опционально. Старый формат остаётся читаемым; пересохранение не требует инференса.

## Open Questions
Уточнить требуемые точки экспорта (JSON, БД, отдельная разметка), точность и интерфейс выбора. YOLO TXT или иной внешний формат пока не обещан: единицы координат не определяют формат файла.
